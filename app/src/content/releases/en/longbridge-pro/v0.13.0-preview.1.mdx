## New
- Assets: Added a brand-new “Funds Details” view.

## Improvements

- Fixed a potential startup issue on Windows.
- Fixed an issue where the title bar buttons on Windows might not respond to clicks.
- Added a “Side” filter to History Orders.
- Optimized the default date range for History Orders.
- Improved keyboard navigation for the stock selection dropdown.
- Fixed the pre-market price display in the Options Chain.
- Positions table now defaults to sorting by market value.
- Fixed some confirmation dialogs where keyboard shortcuts were not working.
