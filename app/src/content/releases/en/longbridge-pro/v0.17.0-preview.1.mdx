## New Features

- **Tray**: Added today's P&L to the macOS menu bar tray, along with the base currency, so you can keep track of the day's gains without opening the main window.

## Improvements

- Fixed a brief blank flash and color jump when switching heatmap tabs.
- Fixed the option calculator not recomputing after input values are updated by the market feed or programmatically.
