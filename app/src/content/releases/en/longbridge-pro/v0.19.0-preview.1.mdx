## Improvements

- **Quant**: Added an abbreviation input to the indicator settings panel, with uniqueness validation and locking after the first save — the indicator name is no longer the only usable identifier.
- Fixed the take-profit/stop-loss P/L ratio steppers dropping the decimal places (e.g. clicking plus on 10.23 produced 11 instead of 11.23).
- Grid trading push notifications now show the owning account at the bottom, making the source clear across multiple accounts; the "Pause" notification is now styled as success instead of a warning.
- Fixed missing minimize/maximize/close buttons on the grid trading order ticket window on Windows.
- Fixed the screener home description overflowing without wrapping, and the grid trading submit-success toast not showing its message.
