## Improvements

- Fixed an issue where an order price tracking Mid / Bid1 / Ask1 only refreshed when a new trade printed; limit orders on thinly traded options no longer fall behind the market because of a stale price.
- Fixed the estimated amount always showing 0 in the confirmation dialog when replacing an untriggered all-position take-profit / stop-loss order.
- Optimized chart indicator calculation, cutting the chart rebuild time caused by quote pushes by about 60% for smoother intraday use in multi-chart layouts.
- Fixed an issue where only the topmost divider could be dragged when multiple sub-chart indicators were open.
