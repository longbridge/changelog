## New features

- **Start chatting, no login required:** Ask the AI right away without signing up—try it first, decide later.
- **Two new models to choose from**:  Build your Agent with Gemini 3.7 Flash or DeepSeek-V4 (GA)—pick the right model for each use case.

## Improvements

- **A cleaner interface**: Refreshed global prompt styling with consistent drawer and sidebar sizing, and memory-organizing summaries now appear in a lightweight popover—less visual clutter.
- **Clearer data sources:** All financial data references are now labeled "Longbridge Data," so you always know where the numbers come from.
- **Tidier benefit descriptions:** Long benefit entries are truncated to one line—hover to see the full text.

## Bug fixes

- Fixed an issue where connectors in draft status incorrectly showed an "Add" entry.
- Fixed an issue where workflows could occasionally freeze and stop responding.
