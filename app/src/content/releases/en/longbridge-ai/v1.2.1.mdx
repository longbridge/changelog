## Improvements

- Smoother access without an account: When no relevant permissions are selected, the trading password step is skipped so you can get started right away.
- Polished interface details: Unified scrollbar styling plus fixes to button spacing, dropdown wrapping, card taps, content overflow, and more—for a smoother feel.

## Bug fixes

- Fixed an issue where a network error could show a 403 page when loading an Agent.
- Fixed an issue where the model could occasionally stall and stop responding.
