Unless otherwise noted, the following updates apply to the LongbridgeAI web version.

## Highlights

### Ask follow-ups on selected text in a side chat

To ask about one sentence in an answer, select the text and click Ask in side chat or Explain. A side chat opens on the right without interrupting the main chat. The side chat can see the main chat's context, supports multiple tabs, and its conclusion can be added as a note below the original answer. Paragraphs show how many side chats they have, and clicking a quote takes you back to the original text. Note: Side chats do not appear in the chat list or history search and cannot be shared. They are deleted together with the main chat.

### Search and filter artifacts

On the Artifacts page, search by title, separating several words with spaces, or filter by type such as documents, web pages and spreadsheets, with a count next to each type. When you return from an item, your search, filter and scroll position are kept. Note: Refreshing the page resets the search.

## LongbridgeAI

**Improvements:**

1. **Scheduled tasks waiting for authorization**: When a scheduled task needs Longbridge authorization and you haven't responded yet, the task skips the steps that need it, gives you the other results first, and marks the report as partially complete. When the next run starts, the previous authorization prompt is removed automatically. If you authorize later, the task reads the latest quotes and holdings again. Note: You cannot run now or retry while authorization is pending.

2. **More accurate citation sources**: Answers citing news search results show source markers, and reprinted articles link to their original source. Cited web pages show the site name or domain.

**Bug Fixes:**

1. **Stock comparison supports indexes and dotted symbols**: Stock comparison cards no longer drop indexes such as .VIX.US or symbols such as BRK.B.US.

2. **Charts display when consulting official agents**: After the AI consults an official agent in a chat, the consultation details show charts, quote cards and source markers the same way as the main answer.

3. **Errors after switching accounts**: After switching accounts in the same browser, "Insufficient permissions" no longer pops up. If the chat list fails to load, you are told and can retry.

**Usage Changes:**

1. **Clear prompt when your account is not opened**: When the current account has not been opened, the AI tells you to open an account or switch to an opened one, instead of asking for authorization or your trading password. This applies only to Longbridge Securities accounts; other brokers connected through connectors are queried as usual.

2. **Check your usage when it runs out**: The button in the "usage used up" banner at the top of the chat page is now View usage, so you can check your usage and benefits first.

## LongbridgeAI in Hong Kong

Unless otherwise noted, the following updates apply to all versions in Hong Kong.

**Improvements:**

1. **Answers lead with the conclusion and back up each judgment**: Factual questions are answered in a sentence or two. Analytical answers start with the conclusion, then expand under subheadings, with data behind each judgment. Trends such as "growth is slowing" or "at a low level" are based on several periods of data. When data is incomplete, the AI gives an evidence-based estimate and labels it as one.

2. **Charts and quote cards appear when they help**: Each point in an answer uses text, a table, a chart or a quote card as needed: charts for trends, gaps and rankings, tables for exact numbers, and quote cards that link to stock details when one to five stocks are discussed. Concepts are explained in text, with diagrams only when you ask.

3. **Six types of questions draw on official agents**: For technical analysis, reasons for stock moves, popular stocks, the semiconductor supply chain, macro topics and a company's main business, the AI first consults the matching official agent and brings its analysis into the answer. Simple quotes and concept explanations are unchanged. This applies to the App and web version.

4. **Quick answers to simple questions**: Concepts, terms, product features, trading rules and a single stock's real-time quote get a quick answer that addresses only what was asked. Questions that need data, calculation, comparison or judgment get a full standard analysis.

5. **Answers start appearing sooner**: Several preparation steps now run at the same time, so the answer text appears sooner after you ask.

6. **Answers follow the language of your question**: When the sources found are in English, the answer still uses the language of your latest message.

**Bug Fixes:**

1. **Watchlist bubble cards display correctly**: When you tap an AI bubble on the watchlist page, such as this week's events after adding a stock or a holdings snapshot after buying, the answer includes the matching card. This applies to the App.

**Usage Changes:**

1. **How to open an account is explained in text in the App**: When you ask about holdings or other topics that need an opened account in the App, the AI explains how to open an account in text. Other buttons, such as deposit and risk assessment, still appear as usual. This applies to the App.

2. **Clear notice when your allowance runs out**: When this month's allowance for creating online documents, files or scheduled tasks runs out, the AI tells you directly, with an upgrade button when an upgrade is available.

## My Agents and Workflow Building

**New Features:**

1. **Choose Azure GPT-6 series models**: When choosing a model for an agent, you can now select `gpt-6.2-astra`, `gpt-6.2-sol`, `gpt-6-luna` and `gpt-6.1-terra` through Azure. Usage is billed at each model's model card price. Note: Thinking can be turned off for `gpt-6-luna` and `gpt-6.1-terra`, but not for either gpt-6.2 model.

**Improvements:**

1. **Handling tool errors and publishing**: Tool errors state whether a retry is possible, so agents don't keep calling tools that cannot be retried. If automatic translation fails for one language when publishing an agent, only that language is skipped and publishing completes.

**Bug Fixes:**

1. **Tool selection on the skills page**: When choosing tools on a skill's details page, Longbridge tools are listed correctly. Tools already added show their names and no longer appear in the list of choices.

**Usage Changes:**

1. **Code runs in a new environment**: Agent code execution, workflow code nodes and hook scripts now run in a new environment with Python 3.13. Note: Runs fail if the return value plus printed output exceeds 1 MB. Python 3.13 removed modules such as `imp`, `cgi`, `pipes` and `telnetlib`, so code nodes that use them need to be rewritten. Hook scripts cannot access the network.

2. **Plugin nodes look for tools only within the same source type**: When a plugin node cannot find a tool in its configured source, it no longer uses a same-named tool from another authorization source. It reports that the tool does not exist and the node fails, without showing an authorization prompt that cannot succeed. Note: Make sure each plugin node's tool source is set correctly.
