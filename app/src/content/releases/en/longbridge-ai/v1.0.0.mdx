## New Features

- Added Kimi-K3, the DeepSeek series, and the latest Claude for better answers. Kimi-K3 is available on all plans.
- Claim rewards without leaving the chat—finish a task and claim in one tap.
- Added financial data to AI chat citations: When an answer cites market quotes, candlestick charts, or other financial data, tap to view the source details.

## Improvements

- Moved the sidebar's pinned shortcuts higher for easier access, and removed the "Previously Used Agents" list for a cleaner look.

## Bug Fixes

- Fixed an issue where scheduled tasks occasionally ran more than once.
