Unless otherwise noted, the following updates are available on the LongbridgeAI web and mobile web versions, and the AI built into the Longbridge App will roll out with upcoming App updates.

## Highlights

### Have the AI build web pages you can open online

Web pages built by the AI can be viewed in the conversation, opened full screen, downloaded, and annotated, and shared links always show the latest version. Before others can view a page, change its sharing setting to "Anyone can view"; removing it from My Artifacts also deletes it permanently. It is also available in the AI built into the Longbridge App in Hong Kong and Singapore.

<Figure src="/assets/longbridge-ai/1.4.1/online-web-page-en.webp" alt="An NVIDIA overview web page built by the AI opens beside the conversation, with annotate, download, and full-screen buttons at the top" caption="The artifact card in the conversation and the web page opened on the right" width={2400} height={1247} />

### AI-built dashboards show the latest data when reopened

When the AI builds a web page that needs data, such as a market dashboard, it declares the data it needs and refreshes it automatically every time the page is opened, instead of freezing at the moment it was created. The bottom of the dashboard shows when the live data was last updated, and shared links show the latest data too. Web and mobile web only.

<Figure src="/assets/longbridge-ai/1.4.1/live-dashboard-en.webp" alt="An NVIDIA and AMD live market dashboard built by the AI opens beside the conversation, showing the latest prices, changes, and intraday charts" caption="The panel shows when the data was last checked, and the live data update time at the bottom" width={2400} height={1247} />

### Jump back to any turn in a long conversation

Once a conversation has more than 3 turns, an outline bar appears on the right. Hover to preview a turn and click to jump to it. Web and mobile web only.

<Figure src="/assets/longbridge-ai/1.4.1/conversation-outline-en.webp" alt="Hovering over a marker on the outline bar shows that turn's question and answer summary" caption="The outline bar sits at the far right, with one marker per question" width={2400} height={1247} />

### Share an Agent with others

Click "Share" at the top right of an Agent's introduction page to create a shareable image with a QR code or copy a link. Web and mobile web only.

<Figure src="/assets/longbridge-ai/1.4.1/agent-share-en.webp" alt="The Agent sharing dialog, with options to download a shareable image or copy a link" caption="Scan the QR code on the image to start using the Agent" width={2400} height={1247} />

### Website AI suggests questions based on the current page

Open the AI on a stock or article page of the Longbridge website, and the suggested questions focus on that stock or article.

<Figure src="/assets/longbridge-ai/1.4.1/website-ai-suggestions-en.webp" alt="Opening the AI on the NVIDIA stock page shows four suggested questions, all about NVIDIA" caption="Suggested questions change with the page you are on" width={2400} height={1247} />

### Standalone release notes page

Release notes open without signing in, making them easy to forward. Web and mobile web only.

<Figure src="/assets/longbridge-ai/1.4.1/release-notes-page-en.webp" alt="The standalone release notes page lists updates by version" caption="Opens without signing in" width={2400} height={1247} />

### Clear progress for multi-step tasks

When the AI works through a multi-step task, a plan list appears above the input box. Expand it to see the status of each subtask; it collapses when the task is done.

<Figure src="/assets/longbridge-ai/1.4.1/plan-progress-en.webp" alt="The expanded plan list above the input box shows four subtasks and their status" caption="Expand the list at any time to check progress" width={2400} height={1247} />

### Download online documents as Word, PDF, or Markdown

Open an online document from My Artifacts or a conversation and download it from the top right. Web and mobile web only.

<Figure src="/assets/longbridge-ai/1.4.1/doc-download-formats-en.webp" alt="The download menu in an online document lists Word, PDF, and Markdown" caption="The download button is at the top right of the document" width={2400} height={1247} />

### Risk assessment opens beside the conversation

Click the risk assessment entry in an answer, and it opens on the right side of the page, so you can stay in the conversation. Tapping "Deposit" on a paper trading account now shows that deposits are not supported.

<Figure src="/assets/longbridge-ai/1.4.1/action-entry-drawer-en.webp" alt="Clicking the risk assessment entry in an answer opens it on the right while the conversation stays on the left" caption="Close the panel to return to the conversation" width={2400} height={1247} />

### Resizable sidebar and collapsible groups

Drag the right edge of the left sidebar to resize it, click a group name to collapse it, and see conversations sorted by most recent activity. Web and mobile web only.

<Figure src="/assets/longbridge-ai/1.4.1/sidebar-resize-collapse-en.webp" alt="A widened sidebar with the Today group collapsed" caption="Drag the sidebar edge to resize, and click a group name to collapse it" width={2400} height={1247} />

## LongbridgeAI

### New features

- **The AI can look up financial data and check facts**: When answering questions, the AI can retrieve financial data directly and check facts. Available on all versions.

### Improvements

- **Full questions when the AI asks you something**: Long questions and options are no longer cut off, and multi-part questions show which page you are on.
- **Interface details**: Menu links on the release notes page are visible again in dark mode, and the action bar under answers now appears when you hover over it.

### Bug fixes

- **P&L card display**: P&L cards in conversations no longer appear as raw data.

### Usage changes

- **Sharing a conversation also makes its artifacts public**: When you share a message or an entire conversation, the online documents, web pages, and other artifacts in it are also made public, so anyone with the link can view them. Make sure this content can be made public before sharing. In effect on all versions.
- **Continue from where you left off after trading password verification**: After you verify your trading password, the answer continues from where it paused without asking again; if you cancel, the prompt no longer keeps reappearing. A brokerage account is required.

## My Agents and workflow building

### New features

- **Ask users to fill in a form during a conversation**: Agents can use the `RequestUserForm` tool to pause during a run, ask users to fill in a form, and continue after it is submitted. Form questions are provided by the platform based on the form ID; custom questions are not yet supported.
- **Set a reasoning budget for your Agent**: Set two reasoning usage limits for an Agent. Beyond the first, thinking depth is lowered automatically; beyond the second, the model stops calling tools and answers directly. Without these settings, behavior is unchanged.
- **Enable "Auto" thinking depth for your Agent**: Once enabled, users start conversations with the system choosing the thinking depth for each question by default, and the allowance used depends on the depth selected.
- **Timeline and Context in run logs**: Run logs have Timeline and Context tabs, showing the order and duration of each node and the context of the run.
- **Azure DeepSeek-V4.1-Flash model available**: The model list now includes `DeepSeek-V4.1-Flash` via Azure.
- **Weekly reports for Agent creators**: Creators who have published Agents receive a weekly report with data such as how many times their Agents have been shared.

### Bug fixes

- **Thinking summary titles**: Summary titles are no longer lost when generated slowly.
- **Question classifier output**: The question classifier node now has structured output turned on by default, so classification results no longer fail to parse.
- **Canvas editing after workflow import**: After importing a DSL, imported connections can be deleted normally, and undo no longer clears the whole canvas.
- **MCP resource and prompt updates**: After a custom MCP is refreshed or reconnected, resource templates and prompts update as well; missing resources return a not-found response.
- **OpenAPI authorization callback URLs**: Authorization completes normally after you add a local callback URL, and existing applications can switch to the new URL.
- **Workflow run fault tolerance**: Workflows skip unsupported environment variable types and return an error message when an iteration node has the wrong data source type, instead of interrupting the run.
