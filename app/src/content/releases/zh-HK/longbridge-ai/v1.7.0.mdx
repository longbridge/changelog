除特別註明外，以下更新適用於 LongbridgeAI 網頁版。

## 重點介紹

### 自訂 AI 的回答方式

在「設定 → 個人化」中選擇回答風格和語氣，填寫你希望 AI 遵循的要求。自訂指令優先於記憶，目前對話中的臨時要求優先，指令不會寫入記憶。

<Figure src="/assets/longbridge-ai/1.7.0/custom-instructions-zh-hk.webp" alt="自訂指令、暱稱與職業的設定示範" caption="按自己的需要設定 AI 回答方式" width={2400} height={1091} />

### 置頂常用對話並尋找歷史回答

在側邊欄置頂最多 20 個常用對話，定時任務對話獨立分組；「全部對話」可搜尋標題、提問和回答。可按狀態篩選與多選對話，「全部標為已讀」作用於所有對話。

<Figure src="/assets/longbridge-ai/1.7.0/conversation-pins-zh-hk.webp" alt="側邊欄置頂分組與對話搜尋入口" caption="集中查看常用對話與歷史回答" width={2400} height={1091} />

### 下載更多類型的成果檔案

讓 AI 產生更多類型的可下載檔案，並在成果面板查看原始碼。可執行檔和安裝套件除外；未登記類型僅供下載，不能公開分享，分享整個對話時會略過並提示，Jupyter 筆記本需下載後用 Jupyter 開啟。

## LongbridgeAI

**新增功能：**

1. **直接預覽文件與表格成果**：在成果面板或「我的成果」中，可直接預覽 PDF、Word、Excel、圖片、CSV/TSV、文字和程式碼。CSV/TSV 可切換表格與原始碼檢視，Excel 可切換工作表。注意：PPT/PPTX、舊版 .doc/.xls 仍需下載查看；檔案過大或預覽失敗時，可下載原檔。

2. **批次取得資料進行複雜分析**：使用中檔或更高思考檔位，比較多隻股票或統計多年財務資料時，AI 可批次取得所需資料後統一計算。本項已從灰度開放至香港、新加坡各端的主對話、自選股熱點和訪客入口。

**體驗優化：**

1. **查看計劃中每一步的進度**：AI 按計劃執行時，展開計劃卡片即可查看各步驟的狀態、用時、說明和呼叫的工具。卡片同時彙總目前進度與中斷位置。注意：舊訊息沒有記錄的步驟說明、用時等資訊不會補顯示。

2. **查看記憶更新與偏好儲存結果**：在記憶設定中提交內容後，可逐條查看已記住、已更新、已刪除或已合併等處理結果。修改偏好時也會顯示儲存狀態。

3. **查詢行情與新聞時直接獲得回答**：問股價或新聞時，AI 會預先取得相關資料，在第一輪回答中使用，並顯示查詢了哪些資料。持倉、餘額等帳戶資訊不在預先取得的範圍內。本項適用於香港、新加坡各端的主對話、自選股熱點和訪客入口。

4. **深度思考使用新模型**：選擇「深度」檔，或「自動」檔判斷問題需要深度分析時，由 `gpt-6.1-terra` 回答；淺檔和中檔維持原有模型。本項適用於香港、新加坡各端的主對話、自選股熱點和訪客入口。

5. **查詢長橋客戶端支援的系統**：詢問長橋有哪些客戶端、是否支援 Windows 等系統時，AI 會參考官網下載頁回答。本項適用於香港、新加坡各端的主對話、自選股熱點和訪客入口。

6. **美國地區回答結合催化劑與策略訊號**：在美國地區各端詢問個股時，AI 會結合可能影響股價的事件和策略訊號回答；詢問大市或市場機會時，會彙總各策略的最新訊號。未開通相應服務卻詢問投資推薦時，會先說明服務狀態，再顯示該股票的催化劑與最新訊號，作為策略觀點。

**問題修復：**

1. **推理計時與引用圖示顯示**：查看回答過程時，推理卡和計劃卡的計時不再倒退或多計一秒，推理耗時包含思考時間。引用來源的網站圖示也修復了大量顯示為通用地球圖示的問題。

2. **傳送後切換對話與附件清理**：新對話發出首問後立即切走，不再被拉回或替換正在查看的對話，已傳送的文字也不會留在輸入框中。首頁附上附件傳送後，對話頁不再殘留已傳送附件；收起側邊欄後，展開提示會正常消失。

3. **減少大表格讀取中的多餘空格**：上傳 Excel、CSV 等大表格時，用於對齊的多餘空格不再佔用 AI 可讀取的內容。本項適用於各端；注意：超出讀取預算的部分仍會截斷，AI 無法讀取這些內容。

4. **回答被攔截時顯示明確提示**：內容審核攔截提問時，會提示「請調整提問後再試」。模型服務商過濾最終回答時，對話會提示失敗，不再顯示成功卻沒有回答；本項適用於各端。

5. **自動續費保留兩小時寬限期**：透過 Stripe 自動續費時，訂閱到期後有 2 小時寬限期，期間仍可使用訂閱權益。延遲收到的付款結果按續費處理；本項適用於網頁版和行動網頁版的 Stripe 訂閱。

6. **開休市資訊與盤中價格表述**：詢問市場開休市或假期安排時，AI 會依據交易日曆回答，無法確認時不作判斷。同時進一步修復將盤中「最新價」稱為「收市價」的問題。本項適用於香港、新加坡各端的主對話、自選股熱點和訪客入口。

7. **醫療類問題的回答範圍**：詢問症狀、用藥劑量、治療方案或化驗結果時，AI 使用統一的簡中、繁中或英文提示，不提供醫療建議；緊急情況提示盡快聯絡急救。醫藥股估值等投資問題仍可回答，混合問題中的投資部分也會保留。本項適用於香港、新加坡各端的主對話、自選股熱點和訪客入口。

8. **附件讀取失敗後繼續回答**：附件損壞或格式不支援時，AI 會說明附件未能讀取並提示重新上傳，同時繼續回答問題的其他部分。本項適用於香港、新加坡各端的主對話、自選股熱點和訪客入口。

9. **檔案交付失敗後自動重試**：讓 AI 產生程式碼、表格或資料檔案時，交付失敗後會自動重試，並說明檔案是否交付成功。本項適用於香港、新加坡各端的主對話、自選股熱點和訪客入口。

**使用調整：**

1. **首頁推薦問題的回答方式**：登入後，首頁推薦問題的首問和推廣到達頁的營運問題由熱點問題 Agent 回答，後續追問仍由通用對話回答；首頁推薦首問不使用個人資料。相同問題、語言和思考檔位的回答可能在不同用戶間重用，直接重用已有回答時，該輪不扣額度。需要產生回答時，由提問者按實際呼叫的模型和套餐係數扣額度，單價可能與通用對話不同，存取權限與額度檢查也按熱點問題 Agent 執行。注意：本次調整不包含訪客提問。

## 我的 Agents 與工作流程搭建

以下更新適用於我的 Agents 與工作流程搭建；Agent 卡片的介面更新適用於網頁版。

**新增功能：**

1. **提前收到模型下架提醒**：Agent 使用的模型即將下架時，會在下架前 14、3、1 天及下架時提醒。模型選擇中會標明「即將下架」或「不可用」，並在有推薦替換模型時顯示提示；注意：推薦不會自動更改 Agent 設定，需自行更換。提醒透過 Longbridge App 推播和站內信傳送，不發電郵；接收者為 Agent 建立者、工作區擁有者及仍有編輯權限的成員，僅限 Longbridge 帳戶，不包含企業租戶成員、訪客和外部簽發身分。香港、新加坡 App 合併涵蓋，不重複傳送；美國範圍的通知發往美國 App，同一則通知每人每分鐘最多 1 則。

2. **工作流程執行失敗時收到通知**：已發佈的工作流程在正式執行中失敗時，會透過 Longbridge App 推播和站內信通知 Agent 建立者、工作區擁有者及仍有編輯權限的成員，不發電郵。正式執行包括定時、Webhook、API 和執行頁手動觸發；同一工作流程對同一人每分鐘最多 1 則。注意：僅限 Longbridge 帳戶，不包含企業租戶成員、訪客和外部簽發身分；香港、新加坡 App 合併涵蓋，不重複傳送，美國範圍的通知發往美國 App。

**體驗優化：**

1. **查看 Agent 的發佈與可見狀態**：在「我的 Agents」卡片中，可查看發佈或編輯日期、可見範圍和被複製次數。編輯後尚未發佈的內容會顯示「上次編輯未發佈」，幫助你區分已儲存與已發佈的修改。

**問題修復：**

1. **修改 Agent 設定保留其他開關**：儲存 Agent 的某一項設定時，不再意外關閉其他開關。鎖定狀態只能透過鎖定入口修改。

2. **工作流程變數與參數錯誤處理**：透過 API 等方式執行沒有對話的工作流程時，對話變數會使用宣告的初始值。節點參數解析失敗時會明確報錯，不再按 0 繼續執行。

3. **知識庫文件解析狀態更明確**：知識庫文件會排隊解析，同時最多處理 2 個。解析逾時會顯示失敗，不再一直停在「索引中」；排隊期間刪除的文件不會繼續解析。

**使用調整：**

1. **更換已下架的直連模型**：Anthropic 直連渠道的 `claude-sonnet-4-5` 已於 11 月 2 日下架。仍在使用它的 Agent 不會自動遷移，請手動更換，推薦使用 `claude-sonnet-5-5`，用量按新模型的模型卡定價計費。注意：AWS Bedrock 渠道的同名模型不受本次調整影響。

2. **獨立選擇「請用戶填表」工具**：需要讓用戶填寫資訊時，請在 Agent 的工具列表中勾選「請用戶填表」（`RequestUserForm`）。僅開啟人機互動開關不再自動啟用該工具；注意：現有 Agent 不會自動補選，此前依賴該開關的作者需要手動勾選。

3. **定時執行期間的任務操作限制**：定時任務執行期間，Agent 不能新增、修改或刪除定時任務。工作流程可使用 `sys.is_scheduled_task` 判斷是否由定時任務觸發，請檢查依賴這些操作的工作流程。
