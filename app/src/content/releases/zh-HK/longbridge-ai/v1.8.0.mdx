除特別註明外，以下更新適用於 LongbridgeAI 網頁版。

## 重點介紹

### 按任務查看定時任務的新結果

每個定時任務在會話列表中只佔一行，顯示最新一次執行和未讀條數；可以單獨分組，也可以直接在側邊欄刪除。注意：刪除定時任務會一併刪除它執行產生的會話、這些會話的分享連結，以及從中總結出的長期記憶，且無法復原。

<Figure src="/assets/longbridge-ai/1.8.0/scheduled-task-rows-zh-hk.webp" alt="側邊欄「定時任務」分組中，美股晨報任務佔一行，並標出 2 條新內容" caption="每個定時任務只佔一行，新結果一目了然" width={2400} height={1211} />

### 切換為日語介面

在左下角帳戶選單的「語言」中選擇「日本語」，介面、錯誤提示和工具名稱都會顯示為日語。個別尚未翻譯的文字會顯示為英文。

<Figure src="/assets/longbridge-ai/1.8.0/japanese-interface-zh-hk.webp" alt="日語介面下開啟帳戶選單的「言語」，語言列表中已選中「日本語」" caption="在帳戶選單中切換為日語介面" width={2400} height={1211} />

### 把好用的 Agent 分享給朋友

在 Agent 對話中讚好回答或連續追問後，輸入框上方會出現分享提示，方便你把這個 Agent 推薦給朋友。提示可以關閉，也可以選擇「不再提示」；私人 Agent 不會提示。

<Figure src="/assets/longbridge-ai/1.8.0/agent-share-prompt-zh-hk.webp" alt="讚好 Agent 的回答後，輸入框上方出現「覺得「技術面分析」好用？」分享提示" caption="遇到好用的 Agent，可以直接分享給朋友" width={2400} height={1211} />

## LongbridgeAI

**新增功能：**

1. **在自選頁一鍵向 AI 提問**：自選頁的 AI 快捷提問已正式開放，點擊即可查看自選股摘要和相關新聞、一鍵加入自選，買入後也能查看持倉卡片。本項適用於香港地區各端。

2. **一句話查看自選股今天的動態**：問「我的自選今天怎麼樣」「持倉裡哪些股票有新聞」時，AI 會直接展示自選股和持倉的今日動態卡片，按重要程度排列，不用逐隻詢問。本項適用於香港地區各端。

**體驗優化：**

1. **找到尚未連接的連接器工具**：AI 尋找可用工具時，也能找到尚未授權的連接器中的工具，並提示你先完成授權。深色模式下，連接器會顯示深色圖示。

2. **長橋行情與帳戶授權自動續期**：授權因長時間未使用而過期後，再查詢行情或帳戶時，系統會按基礎權限自動續期，不再要求你重新授權。注意：你主動撤銷過的授權不會自動續期。本項適用於網頁版、行動網頁版和 Longbridge App 內建 AI。

3. **問題不夠具體時直接回答**：只說了股票名稱、沒說明市場，或使用縮寫提問時，AI 會按最合理的理解直接回答，並說明是按哪種理解作答，你可以隨時換個角度追問。只有不同理解會得出完全不同的答案時，才會給出選項卡片讓你選擇，不再用文字反問。本項適用於香港地區各端。

4. **問入金、開戶時附上辦理按鈕**：詢問「網頁版能入金嗎」「開戶要多久」等問題時，AI 回答後會附上對應的辦理按鈕，不用另找入口。只問歷史記錄、一般概念，或目前帳戶無法辦理的業務時，不會附按鈕。本項適用於香港地區各端。

5. **App 使用問題參考同步後的幫助中心**：回答 App 使用問題時參考的幫助中心文章已與官網同步，新增和改版的文章都能查到。本項適用於香港地區各端。

**問題修復：**

1. **「停止回答」恢復生效**：修復點擊「停止回答」後，回答仍繼續生成的問題。本項適用於各端。

2. **回答中途中斷時提示重試**：回答中途中斷時，不再把被截斷的內容當作完整回答，而是提示「大模型回應中斷，請稍後重試」，部分情況下會自動重試；定時任務遇到這種情況也會重試。注意：看到該提示時，重新提問即可。本項適用於各端。

3. **連線中斷後自動恢復回答**：連線中斷後，會立即檢查回答狀態：已完成的直接顯示，未完成的繼續接收，不再一直停在「生成中」。重新連線期間點擊停止，也不會被拉回生成狀態。

4. **跨地區存取不再被登出**：用其他地區的帳號開啟頁面時，不再被強制登出，而是以訪客身份瀏覽，並提示你到帳號所在地區登入。

5. **在對話中建立週期性定時任務**：修復部分模型下，讓 AI 建立每日、每週或每月定時任務時失敗的問題。注意：此前建立失敗的任務需要重新建立。本項適用於各端。

6. **回答中的新聞來源恢復顯示**：AI 引用新聞時，回答中重新顯示來源標記，可以點開查看新聞原文。本項適用於各端。

7. **生成的 Excel 直接顯示計算結果**：AI 生成的 Excel 中，由公式計算的儲存格在預覽時不再顯示為空白，例如交易記錄的匯總欄和統計頁。需要表格自動重算時，可以要求保留公式。本項適用於香港地區各端。

8. **上傳附件後不再誤報「沒收到檔案」**：AI 會根據附件內容回答，不再誤以為檔案沒有上傳而反覆要求重傳。AI 不會直接修改原檔案，需要修改時會生成一份新檔案；只有附件確實讀取失敗時，才會請你重新上傳。本項適用於香港地區各端。

9. **個股策略信號恢復查詢**：修復詢問某隻股票的策略信號時，部分情況下查不到結果的問題，現在可以正常返回該股票的最新信號。本項適用於香港地區各端。

**使用調整：**

1. **訪客可提問的範圍**：未登入時，可以詢問行情、基本面、財務、新聞和 App 使用問題。訪客入口不聯網搜尋、不開啟外部連結，也不執行程式碼；需要官方公告原文、業績會實錄等資料時，AI 會說明無法搜尋網頁，並用已有數據回答。新聞中的說法會註明出處和日期，App 使用問題會附上對應幫助文章的標題和連結。本項適用於香港地區的訪客入口。

## 我的 Agents 與工作流程搭建

**新增功能：**

1. **為上鎖的 Agent 指定可編輯成員**：在 Agent 編輯頁的權限設定中上鎖時，可以從本空間有編輯權限的成員中「指定可編輯成員」。被指定的成員可以編輯這個 Agent，但不能刪除它或修改編輯權限；成員離開空間或失去編輯權限後，會自動移出名單。

2. **把工作流程產生的圖片儲存到社區**：在工作流程的工具節點中使用「上傳圖片到社區 CDN」，可以把圖片模型產生的圖片轉為永久連結，用於發佈到社區；支援 JPEG、PNG、GIF、WebP，最大 20 MB。注意：上傳後，任何取得連結的人都能開啟這張圖片；該工具只能在工作流程中使用，對話中的 AI 不會呼叫。

3. **選用更多 Kimi 與 DeepSeek 模型**：為 Agent 選擇模型時，可選用 Kimi 國際站的 `kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed`、`kimi-k3`，中國內地 Kimi 渠道的 `kimi-k3`，以及 Azure 渠道的 `DeepSeek-V4.1-Flash-1017`。用量按各模型的模型卡定價計費。

**體驗優化：**

1. **查看 HTTP 節點的完整錯誤資訊**：HTTP 節點的請求傳回非 200 狀態時，錯誤資訊會附上傳回內容，方便你排查；請求會按節點設定的逾時時間執行。請求 OpenAI、Anthropic、xAI、OpenRouter、Google Gemini 的介面時，不再因出口地區被拒絕。

**問題修復：**

1. **模型參數與工具呼叫**：修復 OpenAI、Claude、Gemini 等模型的部分參數不生效或報錯的問題，例如結構化輸出報錯、Gemini 的 `temperature=0` 被忽略。子 Agent 重新可以使用長橋開放介面工具，需要授權時交回主 Agent 發起授權。工具呼叫出錯的情況也有所減少。
