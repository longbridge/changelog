## LongbridgeAI

### 新增功能

- **Longbridge 數據連接器**：數據接入升級為 Longbridge 官方連接器，補全期權等數據類型，可直接取得更全面、高品質的官方數據，為投資分析與判斷提供更完整的依據。
- **文件成果管理中心**：在 LongbridgeAI 對話中，可要求 AI 以文件交付成果。文件跨會話獨立長期保存在側邊欄成果管理中心，可作為投資資訊載體，在長期追蹤公司或復盤時核對當時的判斷依據與風險，並結合新資訊重新審視投資判斷。

### 體驗優化

- **股票行情卡片升級**：股票行情卡片支援週期、K 線切換及行情分享快照，便於與他人圍繞同一張圖討論走勢、交流判斷。
- **會話等待提示**：在對話中，AI 需要你繼續輸入時，會顯示「在等你回覆」並發送訊息通知，便於及時補充研究問題或相關資訊，繼續推進分析。
- **無障礙支援**：頁面完善鍵盤操作、讀屏支援與窄屏佈局，方便使用鍵盤、讀屏或小屏裝置閱讀分析、提出研究問題。

## 我的 Agents 與工作流程搭建

### 新增功能

- **自訂上下文壓縮**：在 Agent 節點配置壓縮提示詞，可指定長對話中優先保留的投資目標、風險約束與關鍵假設，讓上下文保留規則貼合研究任務。上下文壓縮預設開啟。
- **工作流思考等級**：在工作流開始節點，可用新增的 `sys.thinking_level` 引用前端傳入的思考等級，供後續流程配置使用。
- **變量配置**：在配置介面，可為 Commands、Plugins、Hooks 和 OpenAPI 的引用通道設定所需變量，滿足不同任務的配置需要。

### 體驗優化

- **插件導入**：導入插件時可像導入技能一樣拖曳操作，方便為 Agent 加入所需擴充功能。
- **Agent 建立流程**：建立 Agent 時統一使用已全面開放的新版流程，舊版下線。

### 問題修復

- **工作流 Agent 運行模式**：工作流 Agent 的運行模式在建立後保持固定，修復被意外重設的問題。
