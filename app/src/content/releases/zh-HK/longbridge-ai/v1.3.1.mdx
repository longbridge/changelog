## LongbridgeAI

### 新增功能

- **訪客 Agent 體驗**：未登入時可在廣場體驗公開 Agent，試用額度按 Agent 單獨計算，便於先試用再選擇適合的助手。

### 體驗優化

- **背景回答與完成通知**：等待 LongbridgeAI 回答時，你可以先離開，AI 會在背景繼續回答；稍後返回，或收到回答完成的訊息後再回看，無需一直守著對話。
- **AI 入口頁載入**：官網 `/ai` 頁面縮減首屏資源並按需載入內容，減少首次造訪時需要下載的數據，便於更快進入研究對話。
- **窄螢幕輸入框**：小螢幕下輸入框自動收起為膠囊樣式，避免擠壓操作區，方便輸入研究問題。

### 問題修復

- **連接器授權**：修復連接器授權身分與實際運行身分不一致，以及驗證失效後反覆重試或誤彈重新授權的問題，減少研究過程中的授權干擾。
- **地區識別**：修復新加坡地區用戶被誤識別為香港地區的問題。

### 使用調整

- **資產工具驗證**：呼叫涉及資產的工具時，需通過交易密碼驗證後繼續操作。

## 我的 Agents 與工作流程搭建

### 新增功能

- **GPT-6 模型接入**：模型接入新增 `gpt-6-astra`，支援直連、Azure 和 OpenRouter 三種渠道，便於按現有接入方式選用。
- **市場排行榜工具**：Agent Platform 的內建 MCP 工具新增市場排行榜，支援盤前、盤中、盤後等榜單，為市場資訊生成提供不同時段的數據依據。

### 體驗優化

- **智慧問題分類**：在客服問答分類中，對規則未匹配的問題使用大模型兜底識別，並保持向下相容。
- **直連模型請求**：呼叫直連模型時，自動重試失效連線，減少偶發請求失敗對 Agent 運行的影響。

### 問題修復

- **環境變數金鑰編輯**：修復編輯並儲存環境變數時，遮罩回顯導致已配置金鑰值損壞的問題。
- **工作流匯入**：匯入工作流時，思考等級節點的模型配置不再被清空，減少匯入後重新配置的工作。

### 使用調整

- **工作流請求存取範圍**：工作流 HTTP 請求節點和內建請求工具現已限制可存取的位址範圍。依賴外部服務的工作流需檢查目標服務是否仍可存取。
- **聊天 HTML 渲染**：聊天正文僅渲染白名單中的 HTML 標籤，自訂標籤不再渲染。若 Agent 輸出依賴自訂標籤，請檢查顯示效果並調整輸出。
