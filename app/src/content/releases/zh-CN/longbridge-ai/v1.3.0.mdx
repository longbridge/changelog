## LongbridgeAI

### 新增功能

- **Longbridge 数据连接器**：数据接入升级为 Longbridge 官方连接器，补全期权等数据类型，可直接获取更全面、高质量的官方数据，为投资分析与判断提供更完整的依据。
- **文件成果管理中心**：在 LongbridgeAI 对话中，可要求 AI 以文件交付成果。文件跨会话独立长期保存在侧边栏成果管理中心，可作为投资信息载体，在长期跟踪公司或复盘时核对当时的判断依据与风险，并结合新信息重新审视投资判断。

### 体验优化

- **股票行情卡片升级**：股票行情卡片支持周期、K 线切换及行情分享快照，便于与他人围绕同一张图讨论走势、交流判断。
- **会话等待提示**：在对话中，AI 需要你继续输入时，会显示「在等你回复」并发送消息通知，便于及时补充研究问题或相关信息，继续推进分析。
- **无障碍支持**：页面完善键盘操作、读屏支持与窄屏布局，方便使用键盘、读屏或小屏设备阅读分析、提出研究问题。

## 我的 Agents 与工作流搭建

### 新增功能

- **自定义上下文压缩**：在 Agent 节点配置压缩提示词，可指定长对话中优先保留的投资目标、风险约束与关键假设，让上下文保留规则贴合研究任务。上下文压缩默认开启。
- **工作流思考等级**：在工作流开始节点，可用新增的 `sys.thinking_level` 引用前端传入的思考等级，供后续流程配置使用。
- **变量配置**：在配置界面，可为 Commands、Plugins、Hooks 和 OpenAPI 的引用通道设置所需变量，满足不同任务的配置需要。

### 体验优化

- **插件导入**：导入插件时可像导入技能一样拖拽操作，方便为 Agent 添加所需扩展。
- **Agent 创建流程**：创建 Agent 时统一使用已全量开放的新版流程，旧版下线。

### 问题修复

- **工作流 Agent 运行模式**：工作流 Agent 的运行模式在创建后保持固定，修复被意外重置的问题。
