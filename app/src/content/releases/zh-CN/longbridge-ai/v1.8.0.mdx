除特别注明外，以下更新适用于 LongbridgeAI 网页版。

## 重点介绍

### 按任务查看定时任务的新结果

每个定时任务在会话列表中只占一行，显示最新一次运行和未读条数；可以单独分组，也可以直接在侧边栏删除。注意：删除定时任务会一并删除它运行产生的会话、这些会话的分享链接，以及从中总结出的长期记忆，且无法恢复。

<Figure src="/assets/longbridge-ai/1.8.0/scheduled-task-rows-zh-cn.webp" alt="侧边栏「定时任务」分组中，美股晨报任务占一行，并标出 2 条新内容" caption="每个定时任务只占一行，新结果一目了然" width={2400} height={1211} />

### 切换为日语界面

在左下角账户菜单的「语言」中选择「日本語」，界面、错误提示和工具名称都会显示为日语。个别尚未翻译的文字显示为英文。

<Figure src="/assets/longbridge-ai/1.8.0/japanese-interface-zh-cn.webp" alt="日语界面下打开账户菜单的「言語」，语言列表中已选中「日本語」" caption="在账户菜单中切换为日语界面" width={2400} height={1211} />

### 把好用的 Agent 分享给朋友

在 Agent 对话中点赞回答或连续追问后，输入框上方会出现分享提示，方便你把这个 Agent 推荐给朋友。提示可以关闭，也可以选择「不再提示」；私有 Agent 不会提示。

<Figure src="/assets/longbridge-ai/1.8.0/agent-share-prompt-zh-cn.webp" alt="点赞 Agent 的回答后，输入框上方出现「觉得「技术面分析」好用？」分享提示" caption="遇到好用的 Agent，可以直接分享给朋友" width={2400} height={1211} />

## LongbridgeAI

**新增功能：**

1. **在自选页一键向 AI 提问**：自选页的 AI 快捷提问已正式开放，点击即可查看自选股摘要和相关新闻、一键加入自选，买入后也能查看持仓卡片。本项适用于香港地区各端。

2. **一句话查看自选股今天的动态**：问「我的自选今天怎么样」「持仓里哪些股票有新闻」时，AI 会直接展示自选股和持仓的今日动态卡片，按重要程度排列，不用逐只询问。本项适用于香港地区各端。

**体验优化：**

1. **找到尚未连接的连接器工具**：AI 查找可用工具时，也能找到尚未授权的连接器中的工具，并提示你先完成授权。深色模式下，连接器显示深色图标。

2. **长桥行情与账户授权自动续期**：授权因长时间未使用而过期后，再查询行情或账户时，系统会按基础权限自动续期，不再要求你重新授权。注意：你主动撤销过的授权不会自动续期。本项适用于网页版、移动网页版和 Longbridge App 内置 AI。

3. **问题不够具体时直接回答**：只说了股票名称、没说明市场，或使用缩写提问时，AI 会按最合理的理解直接回答，并说明是按哪种理解作答，你可以随时换个角度追问。只有不同理解会得出完全不同的答案时，才会给出选项卡片让你选择，不再用文字反问。本项适用于香港地区各端。

4. **问入金、开户时附上办理按钮**：询问「网页版能入金吗」「开户要多久」等问题时，AI 回答后会附上对应的办理按钮，不用另找入口。只问历史记录、一般概念，或当前账户无法办理的业务时，不会附按钮。本项适用于香港地区各端。

5. **App 使用问题参考同步后的帮助中心**：回答 App 使用问题时参考的帮助中心文章已与官网同步，新增和改版的文章都能查到。本项适用于香港地区各端。

**问题修复：**

1. **「停止回答」恢复生效**：修复点击「停止回答」后，回答仍继续生成的问题。本项适用于各端。

2. **回答中途断开时提示重试**：回答中途断开时，不再把被截断的内容当作完整回答，而是提示「大模型响应中断，请稍后重试」，部分情况下会自动重试；定时任务遇到这种情况也会重试。注意：看到该提示时，重新提问即可。本项适用于各端。

3. **连接中断后自动恢复回答**：连接中断后，会立即检查回答状态：已完成的直接显示，未完成的继续接收，不再一直停在「生成中」。重连期间点击停止，也不会被拉回生成状态。

4. **跨地区访问不再被登出**：用其他地区的账号打开页面时，不再被强制登出，而是以游客身份浏览，并提示你到账号所在地区登录。

5. **在对话中创建周期性定时任务**：修复部分模型下，让 AI 创建每日、每周或每月定时任务时失败的问题。注意：此前创建失败的任务需要重新创建。本项适用于各端。

6. **回答中的新闻来源恢复显示**：AI 引用新闻时，回答中重新显示来源标记，可以点开查看新闻原文。本项适用于各端。

7. **生成的 Excel 直接显示计算结果**：AI 生成的 Excel 中，由公式计算的单元格在预览时不再显示为空白，例如交易记录的汇总列和统计页。需要表格自动重算时，可以要求保留公式。本项适用于香港地区各端。

8. **上传附件后不再误报「没收到文件」**：AI 会基于附件内容回答，不再误以为文件没有上传而反复要求重传。AI 不会直接修改原文件，需要修改时会生成一份新文件；只有附件确实读取失败时，才会请你重新上传。本项适用于香港地区各端。

**使用调整：**

1. **游客可提问的范围**：未登录时，可以询问行情、基本面、财务、新闻和 App 使用问题。游客入口不联网搜索、不打开外部链接，也不运行代码；需要官方公告原文、业绩会实录等资料时，AI 会说明无法搜索网页，并用已有数据回答。新闻中的说法会注明出处和日期，App 使用问题会附上对应帮助文章的标题和链接。本项适用于香港地区的游客入口。

## 我的 Agents 与工作流搭建

**新增功能：**

1. **为上锁的 Agent 指定可编辑成员**：在 Agent 编辑页的权限设置中上锁时，可以从本空间有编辑权限的成员中「指定可编辑成员」。被指定的成员可以编辑这个 Agent，但不能删除它或修改编辑权限；成员离开空间或失去编辑权限后，会自动移出名单。

2. **把工作流生成的图片保存到社区**：在工作流的工具节点中使用「上传图片到社区 CDN」，可以把图片模型生成的图片转为永久链接，用于发布到社区；支持 JPEG、PNG、GIF、WebP，最大 20 MB。注意：上传后，任何拿到链接的人都能打开这张图片；该工具只能在工作流中使用，对话中的 AI 不会调用。

3. **选用更多 Kimi 与 DeepSeek 模型**：为 Agent 选择模型时，可选用 Kimi 国际站的 `kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed`、`kimi-k3`，国内 Kimi 渠道的 `kimi-k3`，以及 Azure 渠道的 `DeepSeek-V4.1-Flash-1017`。用量按各模型的模型卡定价计费。

**体验优化：**

1. **查看 HTTP 节点的完整报错**：HTTP 节点的请求返回非 200 状态时，错误信息会附上返回内容，方便你排查；请求按节点配置的超时执行。请求 OpenAI、Anthropic、xAI、OpenRouter、Google Gemini 的接口时，不再因出口地区被拒绝。

**问题修复：**

1. **模型参数与工具调用**：修复 OpenAI、Claude、Gemini 等模型的部分参数不生效或报错的问题，例如结构化输出报错、Gemini 的 `temperature=0` 被忽略。子 Agent 重新可以使用长桥开放接口工具，需要授权时交回主 Agent 发起授权。工具调用出错的情况也有所减少。
