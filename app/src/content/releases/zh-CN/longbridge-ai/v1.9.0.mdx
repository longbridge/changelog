除特别注明外，以下更新适用于 LongbridgeAI 网页版。

## 重点介绍

### 用量快用完时提前提醒

本周用量用到 80% 和 90% 时，回答结束后输入框上方会各提醒一次剩余比例，你可以查看用量详情或升级套餐，提前安排要问的问题。用量用完时，提示会写明重置时间，不用再从被拒的消息里找原因。注意：只在登录后显示；关闭剩余用量提醒后，本周期内不再出现。

<Figure src="/assets/longbridge-ai/1.9.0/usage-reminder-zh-cn.webp" alt="输入框上方显示本周剩余用量比例的提醒" caption="用量快用完时，回答结束后会提醒剩余比例" width={2400} height={1285} />

### 一次删除多条会话

整理侧栏时，按住 Shift 逐条点击就能选中多条会话，右键即可一起删除；双击会话标题可以直接重命名。注意：删除前会再次确认，删除后无法恢复。

<Figure src="/assets/longbridge-ai/1.9.0/bulk-delete-chats-zh-cn.webp" alt="侧栏中选中多条会话后弹出的删除菜单" caption="按住 Shift 选中多条会话，右键一起删除" width={2400} height={1285} />

### 选用 gpt-6.2 与 qwen4-max 模型

为 Agent 选择模型时，可选用 OpenAI 的 `gpt-6.2-astra`、`gpt-6.2-sol`，以及阿里云的 `qwen4-max`（支持 100 万上下文）。用量按各模型的模型卡定价计费。注意：两款 gpt-6.2 模型都不支持关闭思考。

<Figure src="/assets/longbridge-ai/1.9.0/new-models-zh-cn.webp" alt="在 Agent 模型列表中搜索 gpt-6.2，两家服务商下都列出 gpt-6.2-astra 与 gpt-6.2-sol" caption="为 Agent 选择模型时可选用新模型" width={2400} height={1285} />

## LongbridgeAI

**体验优化：**

1. **定时任务不再停下来等你回答**：定时任务运行时遇到不确定的地方，AI 会按最合理的理解继续执行，一种方法不行就换一种，尽量把任务做完。实在无法继续时，会先给出已有结果，再用一句话向你提问，你之后在这个会话里回复即可。本项适用于各端。

2. **连接器授权失败时看到具体原因**：连接器授权没有成功时，会直接说明原因，例如已达到可连接的账号上限、这个账号已经连接过、登录的不是要重新连接的账号，或授权已过期，方便你对症处理。

**问题修复：**

1. **套餐和协议按账号所在地区显示**：登录后，套餐页和协议按你的账号所在地区显示，不会因为之前打开过其他地区的推广链接而显示错误的套餐。

2. **深色模式和长文字的显示**：深色模式下，交易密码弹窗跟随页面主题显示；被省略号截断的文字，鼠标悬停即可查看全文。首次访问、没有设置过主题时，默认显示浅色界面。

**使用调整：**

1. **分享的会话不再显示交易卡片**：别人打开你分享的会话时，不会看到下单、账户等交易类卡片。

## 我的 Agents 与工作流搭建

**新增功能：**

1. **在 HTTP 节点上传文件**：在工作流的 HTTP 节点中，请求可以带上文件：选择文件变量，或者 base64、data URL、链接形式的文本变量，就能把文件直接发给外部服务。

**体验优化：**

1. **回答被内容审核拒绝时自动换一家重试**：Agent 或工作流的回答被模型服务商的内容安全审核拒绝时，会自动换另一家服务商重试一次，不再直接失败。注意：只在所选模型配置了多家服务商时生效；重试成功时，按实际回答的模型计费。

2. **工具返回内容过多时不再直接失败**：Agent 批量调用工具、返回的内容超过 64 KiB 时，会先省略其中最长的列表和文本，并注明省略了什么，其余内容照常交给 AI。省略后仍然放不下时才会失败，AI 会据此缩小查询范围。

**问题修复：**

1. **工作流变量、迭代与分支的运行**：变量「追加」后保持原有的数组类型；暂停等待输入后恢复时，不再重复执行已完成的赋值；迭代节点按配置的错误处理方式跳过失败项，不再中断整个迭代；并行分支同时输出时，回答不再重复；只有一条出边的节点也会照常判断条件。

2. **知识库分段预览与运行日志定位**：知识库的分段预览恢复正常；通过消息链接打开运行日志时，页面会直接定位到那条消息。
