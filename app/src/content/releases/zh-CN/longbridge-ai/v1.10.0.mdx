除特别注明外，以下更新适用于 LongbridgeAI 网页版。

## 重点介绍

### 选中文字在侧边追问

想就回答里的某一句再问时，选中这段文字，点「侧边追问」或「解释一下」，右侧会打开侧边对话，不打断主对话。侧边对话能看到主对话的上下文，可以开多个标签，结论可以作为备注插到原回答下方；段落旁会显示这段有几条侧边对话，点引用可以回到原文。注意：侧边对话不出现在会话列表和历史搜索里，不能分享；删除主会话时一并删除。

### 搜索和筛选「我的成果」

在「我的成果」里可以按标题搜索，多个词用空格隔开；也可以按文档、网页、表格等类型筛选，每个类型旁显示数量。从详情页返回时，保留原来的搜索词、筛选和浏览位置。注意：刷新页面后搜索条件会恢复默认。

## LongbridgeAI

**体验优化：**

1. **定时任务等待授权时的处理**：定时任务需要长桥授权而你暂时没有处理时，任务会跳过需要授权的步骤，先给出其余结果，并标明部分完成；下一次运行开始时，上一次的授权提示会自动撤下。之后再授权，任务会重新读取最新的行情和持仓。注意：等待授权期间不能立即运行或重试。

2. **引用来源显示更准确**：回答引用新闻搜索结果时显示来源标记，转载文章链到原文来源；网页引用显示站名或域名。

**问题修复：**

1. **多股对比支持指数和带点的代码**：多股对比卡片里有 .VIX.US 这类指数或 BRK.B.US 这类代码时，不再漏掉这只股票。

2. **咨询官方 Agent 时图表正常显示**：在对话里咨询官方 Agent 后，点开咨询详情，回答里的图表、行情卡片和来源标记与主回答显示一致。

3. **切换账号登录后的报错**：同一浏览器切换账号登录后，不再弹出「权限不足」；会话列表加载失败时会提示并可以重试。

**使用调整：**

1. **账户未开户时直接提示**：当前账户未开户时，AI 会直接告诉你需要开户或切换到已开户的账户，不再引导授权或输入交易密码。这只针对长桥证券账户，通过连接器连上的其他券商照常查询。

2. **额度用完时先查看用量**：会话页顶部「额度已用完」的按钮改为「查看用量」，可以先查看用量与权益。

## 香港地区的 LongbridgeAI

除特别注明外，以下更新适用于香港地区各端。

**体验优化：**

1. **回答先给结论，判断附上依据**：事实类问题一两句话答完；分析类问题先给出结论，再分小标题展开，每个判断都附上数据依据。说「增长放缓」「处于低位」这类趋势时会看多期数据；数据不全时会给出有依据的估计并标明是估计。

2. **图表和行情卡片按需出现**：回答里的每个要点按需要选择文字、表格、图表或行情卡片：看走势、差距、排名时画图，查准确数字时给表格，涉及一到五只股票时附上可点进详情的行情卡片；概念问题用文字讲清楚，你要求时才画示意图。

3. **六类问题先咨询官方 Agent 再回答**：问技术面、个股异动原因、市场热门股、半导体产业链、宏观和公司主营业务时，AI 会先咨询对应的官方 Agent，再把它的分析整合进回答。简单报价和概念解释不受影响。本项适用于 App 与网页版。

4. **简单问题快速作答**：概念、术语、产品功能、交易规则和单只股票的实时报价，AI 会快速回答，只答所问；需要查数、计算、比较或判断的问题，会按标准方式完整分析。

5. **回答更早开始出现**：回答前的几项准备改为同时进行，提问后更快看到回答的文字。

6. **回答语言跟随你的提问**：查到的资料是英文时，回答也会使用你最新一条消息的语言。

**问题修复：**

1. **自选气泡的图卡正常显示**：在自选页点 AI 气泡（如加自选后的本周事件、买入后的持仓快照），回答会带上对应的图卡。本项适用于 App。

**使用调整：**

1. **App 内用文字说明开户方式**：在 App 里问到持仓等需要开户的问题时，AI 会用文字说明开户方式；入金、风险测评等其他按钮照常出现。本项适用于 App。

2. **额度用完时直接说明**：当月生成在线文档、文件或定时任务的额度用完时，AI 会直接告诉你本月额度已用完，可以升级时附上升级按钮。

## 我的 Agents 与工作流搭建

**新增功能：**

1. **选用 Azure 渠道的 GPT-6 系列模型**：为 Agent 选择模型时，可选用 Azure 渠道的 `gpt-6.2-astra`、`gpt-6.2-sol`、`gpt-6-luna` 和 `gpt-6.1-terra`。用量按各模型的模型卡定价计费。注意：`gpt-6-luna` 与 `gpt-6.1-terra` 可以关闭思考，两款 gpt-6.2 不能关闭。

**体验优化：**

1. **工具出错与发布时的处理**：工具报错时会说明能否重试，Agent 不会对无法重试的工具反复调用；发布 Agent 时某种语言自动翻译出错，只跳过这种语言，发布照常完成。

**问题修复：**

1. **技能页的工具选择**：技能详情页选择工具时能正常列出 Longbridge 工具，已添加的工具显示名称，不再出现在可选列表里。

**使用调整：**

1. **代码执行改用新的运行环境**：Agent 的代码执行、工作流代码节点和 hook 脚本改用新的运行环境，Python 升级到 3.13。注意：返回值连同打印输出超过 1 MB 会失败；Python 3.13 已移除 `imp`、`cgi`、`pipes`、`telnetlib` 等模块，用到它们的代码节点需要改写；hook 脚本不能访问网络。

2. **插件节点只在同类来源中查找工具**：插件节点按配置的来源找不到工具时，不再去其他授权来源找同名工具，而是直接提示工具不存在，节点失败，也不再弹出无法完成的授权。注意：请确认插件节点配置的工具来源正确。
