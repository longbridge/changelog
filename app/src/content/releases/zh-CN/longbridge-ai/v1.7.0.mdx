除特别注明外，以下更新适用于 LongbridgeAI 网页版。

## 重点介绍

### 自定义 AI 的回答方式

在「设置 → 个性化」中选择回答风格和语气，填写你希望 AI 遵循的要求。自定义指令优先于记忆，当前对话中的临时要求优先，指令不会写入记忆。

<Figure src="/assets/longbridge-ai/1.7.0/custom-instructions-zh-cn.webp" alt="自定义指令、昵称与职业的设置示例" caption="按自己的需要设置 AI 回答方式" width={2400} height={1091} />

### 置顶常用会话并查找历史回答

在侧边栏置顶最多 20 个常用会话，定时任务会话单独分组；「全部会话」可搜索标题、提问和回答。可按状态筛选与多选会话，「全部标为已读」作用于所有会话。

<Figure src="/assets/longbridge-ai/1.7.0/conversation-pins-zh-cn.webp" alt="侧边栏置顶分组与会话搜索入口" caption="集中查看常用会话与历史回答" width={2400} height={1091} />

### 下载更多类型的成果文件

让 AI 生成更多类型的可下载文件，并在成果面板查看源代码。可执行文件和安装包除外；未登记类型仅供下载，不能公开分享，分享整个会话时会跳过并提示，Jupyter 笔记本需下载后用 Jupyter 打开。

<Figure src="/assets/longbridge-ai/1.7.0/file-downloads-zh-cn.webp" alt="成果面板中的文件下载入口" caption="将 AI 交付的文件下载后使用" width={2400} height={1091} />

## LongbridgeAI

**新增功能：**

1. **直接预览文档与表格成果**：在成果面板或「我的成果」中，可直接预览 PDF、Word、Excel、图片、CSV/TSV、文本和代码。CSV/TSV 可切换表格与源码视图，Excel 可切换工作表。注意：PPT/PPTX、旧版 .doc/.xls 仍需下载查看；文件过大或预览失败时，可下载原文件。

**体验优化：**

1. **查看计划中每一步的进度**：AI 按计划执行时，展开计划卡片即可查看各步骤的状态、用时、说明和调用的工具。卡片同时汇总当前进度与中断位置。注意：旧消息没有记录的步骤说明、用时等信息不会补显示。

2. **查看记忆更新与偏好保存结果**：在记忆设置中提交内容后，可逐条查看已记住、已更新、已删除或已合并等处理结果。修改偏好时也会显示保存状态。

**问题修复：**

1. **推理计时与引用图标显示**：查看回答过程时，推理卡和计划卡的计时不再倒退或多计一秒，推理耗时包含思考时间。引用来源的站点图标也修复了大量显示为通用地球图标的问题。

2. **发送后切换会话与附件清理**：新会话发出首问后立即切走，不再被拉回或替换正在查看的会话，已发送的文字也不会留在输入框中。首页带附件发送后，对话页不再残留已发送附件；收起侧边栏后，展开提示会正常消失。

3. **减少大表格读取中的多余空格**：上传 Excel、CSV 等大表格时，用于对齐的多余空格不再挤占 AI 可读取的内容。本项适用于各端；注意：超出读取预算的部分仍会截断，AI 无法读取这些内容。

4. **回答被拦截时显示明确提示**：内容审核拦截提问时，会提示「请调整提问后再试」。模型服务商过滤最终回答时，对话会提示失败，不再显示成功却没有回答；本项适用于各端。

5. **自动续费保留两小时宽限期**：通过 Stripe 自动续费时，订阅到期后有 2 小时宽限期，期间仍可使用订阅权益。晚到的付款结果按续费处理；本项适用于网页版和移动网页版的 Stripe 订阅。

**使用调整：**

1. **首页推荐问题的回答方式**：登录后，首页推荐问题的首问和推广落地页的运营问题由热点问题 Agent 回答，后续追问仍由通用对话回答；首页推荐首问不使用个人数据。相同问题、语言和思考档位的回答可能在不同用户间复用，直接复用已有回答时，该轮不扣额度。需要生成回答时，由提问者按实际调用的模型和套餐系数扣额度，单价可能与通用对话不同，访问权限与额度检查也按热点问题 Agent 执行。注意：本次调整不包含游客提问。

## 我的 Agents 与工作流搭建

以下更新适用于我的 Agents 与工作流搭建；Agent 卡片的界面更新适用于网页版。

**新增功能：**

1. **提前收到模型下架提醒**：Agent 使用的模型即将下架时，会在下架前 14、3、1 天及下架时提醒。模型选择中会标明「即将下架」或「不可用」，并在有推荐替换模型时显示提示；注意：推荐不会自动更改 Agent 配置，需自行更换。提醒通过 Longbridge App 推送和站内信发送，不发邮件；接收人为 Agent 创建者、工作区所有者及仍有编辑权限的成员，仅限 Longbridge 账号，不包含企业租户成员、游客和外部签发身份。香港、新加坡 App 合并覆盖，不重复发送；美国范围的通知发往美国 App，同一条通知每人每分钟最多 1 条。

2. **工作流运行失败时收到通知**：已发布的工作流在正式运行中失败时，会通过 Longbridge App 推送和站内信通知 Agent 创建者、工作区所有者及仍有编辑权限的成员，不发邮件。正式运行包括定时、Webhook、API 和运行页手动触发；同一工作流对同一人每分钟最多 1 条。注意：仅限 Longbridge 账号，不包含企业租户成员、游客和外部签发身份；香港、新加坡 App 合并覆盖，不重复发送，美国范围的通知发往美国 App。

**体验优化：**

1. **查看 Agent 的发布与可见状态**：在「我的 Agents」卡片中，可查看发布或编辑日期、可见范围和被复制次数。编辑后尚未发布的内容会显示「上次编辑未发布」，帮助你区分已保存与已发布的修改。

**问题修复：**

1. **修改 Agent 设置保留其他开关**：保存 Agent 的某一项设置时，不再意外关闭其他开关。锁定状态只能通过锁定入口修改。

2. **工作流变量与参数错误处理**：通过 API 等方式运行没有会话的工作流时，会话变量会使用声明的初始值。节点参数解析失败时会明确报错，不再按 0 继续执行。

3. **知识库文档解析状态更明确**：知识库文档会排队解析，同时最多处理 2 个。解析超时会显示失败，不再一直停在「索引中」；排队期间删除的文档不会继续解析。

**使用调整：**

1. **更换已下架的直连模型**：Anthropic 直连渠道的 `claude-sonnet-4-5` 已于 11 月 2 日下架。仍在使用它的 Agent 不会自动迁移，请手动更换，推荐使用 `claude-sonnet-5-5`，用量按新模型的模型卡定价计费。注意：AWS Bedrock 渠道的同名模型不受本次调整影响。

2. **单独选择「请用户填表」工具**：需要让用户填写信息时，请在 Agent 的工具列表中勾选「请用户填表」（`RequestUserForm`）。仅开启人机交互开关不再自动启用该工具；注意：存量 Agent 不会自动补选，此前依赖该开关的作者需要手动勾选。

3. **定时运行期间的任务操作限制**：定时任务运行期间，Agent 不能新建、修改或删除定时任务。工作流可使用 `sys.is_scheduled_task` 判断是否由定时任务触发，请检查依赖这些操作的工作流。
