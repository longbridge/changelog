## 新增

- **行情**：新增「股东」面板，可查看个股主要股东及持仓结构，方便研究股权变化。
- 新增 macOS 菜单栏状态项与下拉菜单，可直接在菜单栏查看自选股实时行情、切换分组并快速唤起主窗口，不打开主窗口也能盯盘。
- Windows 支持「关闭到系统托盘」，关闭窗口后应用在后台继续运行，可通过托盘图标快速恢复。
- **登录**：新增长桥香港 / 长桥新加坡地区切换，可按所选地区动态切换。

## 优化

- **设置**：新增「声音设置」，可单独开关股价提醒声音，免打扰时段不再被提示音打扰。
- **搜索**：股票搜索新增「清除历史」按钮，可一键清空搜索记录。
- 优化下单 / 撤单通知，消息中展示具体订单详情（方向、数量、标的、委托价），追踪单以反弹 / 回落格式呈现，便于核对。
