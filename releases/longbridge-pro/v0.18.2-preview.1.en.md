# v0.18.2-preview.1  <Badge type="warning" text="preview" />

_Release Date: 2026-07-28_

### Improvements

- Fixed an issue where indicator scripts with color parameters (e.g. MACD) failed to parse; parameters in the MACD indicator settings panel can now be edited normally.
- Optimized system proxy change detection — in "no system proxy" mode, the network connection is now rebuilt automatically after toggling a VPN or proxy tool, preventing requests from hanging indefinitely.
- Fixed incorrect sorting when sorting the watchlist by the weekly change column.
