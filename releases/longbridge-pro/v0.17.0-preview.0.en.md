# v0.17.0-preview.0  <Badge type="warning" text="preview" />

_Release Date: 2026-06-04_

### New

- **Quotes**: Added a "Shareholders" panel to view a stock's major shareholders and holding structure, making it easier to study ownership changes.
- Added a macOS menu-bar status item and dropdown menu to view real-time watchlist quotes, switch groups, and quickly bring up the main window — monitor the market without opening the main window.
- Windows now supports "Close to system tray" — closing the window keeps the app running in the background, and you can quickly restore it from the tray icon.
- **Login**: Added a Longbridge HK / Longbridge SG region switcher that switches dynamically by the selected region.

### Improvements

- **Settings**: Added "Sound" settings to toggle the stock price alert sound separately, so you won't be disturbed by alert tones during quiet hours.
- **Search**: Added a "Clear History" button to stock search for clearing search records with one click.
- Improved order submit / cancel notifications — messages now show order details (side, quantity, symbol, order price), with trailing orders shown in a rebound / pullback format for easy verification.
