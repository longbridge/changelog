# v1.1.2 

_Release Date: 2026-11-10_

### Improvements

- Fixed an issue with LongbridgeAI voice input recognition.
- Fixed an issue where switching market groups in Holdings might not take effect.
- Fixed an issue where pending take-profit / stop-loss lines disappeared from the chart and could no longer be dragged to adjust the price after the parent order was filled.
- Improved stability on Windows and how the app recovers after the system wakes from sleep.
- Fixed an issue where the option table and unusual options activity did not follow the widget's own link group after the option chain widget was set to unlinked or moved to another link group.
