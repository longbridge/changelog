# v0.16.0-preview.2  <Badge type="warning" text="preview" />

_Release Date: 2026-05-21_

### New Features

- **Stock Reminder**: Added push notification support so reminders are delivered in real time, helping users avoid missing critical price levels.

### Improvements

- **Login**: Improved the network error prompt on the captcha page and added a built-in retry mechanism so users are no longer stuck when the network is unstable.
