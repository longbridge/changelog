## 这一版最想让用户知道的

AI 做的网页可以在线查看、下载与分享；长对话可以一键回到任意一轮；在长桥官网打开 AI 时，推荐问题会跟随当前页面。

## 新增

### LongbridgeAI

除特别注明外，以下更新已在 LongbridgeAI 网页版和移动网页版上线，Longbridge App 内置 AI 将随 App 版本更新陆续开通。

- 让 AI 做一个可在线打开的网页：让 AI 帮你做网页或页面时，它会生成一份在线网页，可以在对话中查看、全屏浏览、下载当前版本，也可以在页面上添加注解；分享链接始终显示网页的最新内容。他人通过链接查看前，需要在分享设置中改为「所有人可见」；从「我的成果」移除网页会同时删除该网页，且无法恢复。香港、新加坡 App 内置 AI 已同步上线。
- AI 做的看板再次打开时显示最新数据：让 AI 做行情看板这类需要数据的网页时，它会声明所需的数据，之后每次打开都会自动取数刷新，不再停留在生成那一刻；看板底部显示实时数据的更新时间，分享链接打开时同样显示最新数据。仅网页版和移动网页版。
- AI 可以查询金融数据并核实信息：AI 回答问题时新增金融数据查询与事实核查两类工具，可以直接调取金融数据，并对信息进行事实核查。已在各端上线。
- 长对话一键回到任意一轮：对话超过 3 轮后，页面右侧会出现目录条，每一轮提问对应一个节点，悬停可预览该轮回答，点击即可跳转。仅网页版和移动网页版。
- 把 Agent 分享给他人：在 Agent 介绍页右上角点击「分享」，可以生成带二维码的分享长图或复制链接，邀请他人直接开始使用。仅网页版和移动网页版。
- 更新日志独立页面：更新日志有了独立页面，无需登录即可打开，方便转发给他人。仅网页版和移动网页版。
- 官网 AI 按当前页面推荐问题：在长桥官网不同页面打开 AI 时，推荐问题会跟随当前页面，例如在个股页推荐与该股票相关的问题，在文章页推荐与该文章相关的问题。仅长桥官网的 AI 入口。

### 我的 Agents 与工作流搭建

- 在对话中弹出表单收集信息：Agent 可以使用新增的 `RequestUserForm` 工具，在运行中暂停并弹出表单请使用者填写，提交后继续执行。表单题目由平台按表单编号提供，暂不支持自定义题面。
- 为 Agent 设置推理预算：可设置两级推理用量上限，超过第一级时自动降低思考深度，超过第二级时要求模型停止调用工具并直接作答。不设置时行为不变。
- 为 Agent 开启「自动」思考深度：开启后使用者进入对话时，默认由系统按问题选择思考深度；每次消耗的额度取决于系统选定的档位。
- 运行日志查看时间线与上下文：运行日志新增「时间线」与「上下文」两个标签页，可以查看各节点的先后顺序、耗时及该次运行的上下文。
- 新增 Azure DeepSeek-V4.1-Flash 模型：模型列表新增 Azure 渠道的 `DeepSeek-V4.1-Flash`。
- Agent 创作者周战报：发布了 Agent 的创作者每周会收到战报推送，了解自己 Agent 的被分享次数等数据。

## 优化

### LongbridgeAI

- 多步骤任务的进度一目了然：AI 执行多步骤任务时，输入框上方会显示计划清单，可展开查看每个子任务的状态，任务完成后自动收起。
- AI 提问时问题显示完整：AI 向你确认问题时，较长的问题与选项不再被截断，多组问题会显示当前页数。
- 侧边栏可调宽、分组可折叠：左侧边栏可以拖动调整宽度，会话分组可以折叠，会话列表按最近活跃时间排序并随滚动加载。仅网页版和移动网页版。
- 在线文档可下载为 Word、PDF、Markdown：在「我的成果」或对话中打开在线文档时，可以直接下载为这三种格式。仅网页版和移动网页版。
- 风险测评在对话右侧打开：点击 AI 回答中的风险测评入口，测评页在页面右侧打开，无需离开当前对话；模拟账户点击「入金」时会提示暂不支持。
- 界面细节：对话页与侧边栏的视觉风格更加统一，各处菜单的外观与展开动画保持一致，深色模式下版本更新页的菜单链接恢复可见，回答下方的操作栏改为鼠标悬停时显示。

## 修复

### LongbridgeAI

- 盈亏卡片显示异常：修复对话中的盈亏卡片在部分情况下显示为原始数据的问题。

### 我的 Agents 与工作流搭建

- 思考摘要标题：修复摘要标题生成较慢时丢失、使用者看到无标题摘要的问题。
- 问题分类器输出：问题分类器节点默认开启结构化输出，提示词不再覆盖输出格式，避免分类结果解析失败。
- 导入工作流后的画布编辑：导入 DSL 后，导入的连线可以正常删除，撤销只会回到导入前的状态，不再清空整个画布。
- MCP 资源与提示词更新：自定义 MCP 刷新或重连后，资源模板与提示词会同步更新；资源不存在时提示未找到，不再返回服务器错误。
- OpenAPI 授权回调地址：新增本地回调地址后可以正常完成授权，已有应用也可以改用新地址。
- 工作流运行容错：工作流遇到不支持的环境变量类型时会跳过，迭代节点的数据源类型错误时会返回错误提示，不再导致运行中断。

## 需要用户注意的

- 分享对话会同时公开其中的成果：分享一条消息或整个对话时，其中引用的在线文档、网页等成果会一并设为公开，拿到链接的人都可以查看。分享前请确认这些内容可以公开。已在各端上线。
- 交易密码验证后从原处继续：需要交易密码的步骤会在原处暂停，验证后从暂停处继续回答，不再重复提问；取消验证后不会反复弹出验证框。需已开户。
