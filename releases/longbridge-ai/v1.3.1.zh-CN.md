## LongbridgeAI

**新增功能：**

1. **游客 Agent 体验**：未登录时可在广场体验公开 Agent，试用额度按 Agent 单独计算，便于先试用再选择适合的助手。

**体验优化：**

1. **后台回答与完成通知**：等待 LongbridgeAI 回答时，你可以先离开，AI 会在后台继续回答；稍后返回，或收到回答完成的消息后再回看，无需一直守着对话。
2. **AI 入口页加载**：官网 `/ai` 页面缩减首屏资源并按需加载内容，减少首次访问时需要下载的数据，便于更快进入研究对话。
3. **窄屏输入框**：小屏下输入框自动收起为胶囊样式，避免挤压操作区，方便输入研究问题。

**问题修复：**

1. **连接器授权**：修复连接器授权身份与实际运行身份不一致，以及鉴权失效后反复重试或误弹重新授权的问题，减少研究过程中的授权干扰。
2. **地区识别**：修复新加坡地区用户被误识别为香港地区的问题。

**使用调整：**

1. **资产工具验证**：调用涉及资产的工具时，需通过交易密码验证后继续操作。

## 我的 Agents 与工作流搭建

**新增功能：**

1. **GPT-6 模型接入**：模型接入新增 `gpt-6-astra`，支持直连、Azure 和 OpenRouter 三种渠道，便于按现有接入方式选用。
2. **市场排行榜工具**：Agent Platform 的内置 MCP 工具新增市场排行榜，支持盘前、盘中、盘后等榜单，为市场资讯生成提供不同时段的数据依据。

**体验优化：**

1. **智能问题分类**：在客服问答分类中，对规则未匹配的问题使用大模型兜底识别，并保持向下兼容。
2. **直连模型请求**：调用直连模型时，自动重试失效连接，减少偶发请求失败对 Agent 运行的影响。

**问题修复：**

1. **环境变量密钥编辑**：修复编辑并保存环境变量时，掩码回显导致已配置密钥值损坏的问题。
2. **工作流导入**：导入工作流时，思考等级节点的模型配置不再被清空，减少导入后重新配置的工作。

**使用调整：**

1. **工作流请求访问范围**：工作流 HTTP 请求节点和内置请求工具现已限制可访问的地址范围。依赖外部服务的工作流需检查目标服务是否仍可访问。
2. **聊天 HTML 渲染**：聊天正文仅渲染白名单中的 HTML 标签，自定义标签不再渲染。若 Agent 输出依赖自定义标签，请检查显示效果并调整输出。
