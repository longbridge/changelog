## LongbridgeAI

除特别注明外，以下功能更新已在 LongbridgeAI 网页版和移动网页版上线，Longbridge App 内置 AI 将随 App 版本更新陆续开通；性能优化已在各端生效。

**新增功能：**

1. **AI 在线协作文档**：在对话中提出写文档的需求，AI 可直接创建和编辑在线协作文档，文档自动保存到「我的成果」，可在会话中直接查看，也可从「我的成果」打开；在文档中留下评论，AI 会在后台处理，无需回到对话重新提问。从「我的成果」移除文档时，对应的在线文档会一并删除且无法恢复。
2. **成果支持图片格式**：AI 生成的成果新增 PNG、JPG、GIF、WebP、SVG 五种图片格式；图片成果目前以下载方式获取，暂不支持在成果面板中直接预览。生成成果时会校验文件类型，不支持的类型会被直接拒绝，避免生成无法打开的文件。
3. **回答中的行情链接**：AI 回答中写出的股票、期权代码（如 NVDA.US、700.HK）经校验后显示为行情链接，点击即可查看行情；无法确认的代码保持纯文本，避免链接到错误的标的。
4. **资产与盈亏分析卡片**：在对话中询问资产与盈亏相关问题时，分析结果以结构化卡片呈现，便于查看账户的资产与盈亏情况。
5. **套餐升级与风险测评入口**：在对话中，AI 可直接给出升级套餐和风险测评的操作入口；套餐列表列出各档位功能的具体额度，便于逐项比较后选择。
6. **思考摘要**：在启用思考摘要的 Agent 对话中，模型的长篇推理以标题和摘要呈现，便于快速了解推理进展。

**体验优化：**

1. **子任务耗时**：对话中的子任务行右侧显示耗时，运行中实时更新，便于了解每个子任务的进度。
2. **成果卡片与预览**：成果卡片按文件类型显示不同的图标与底色，便于区分；深色模式下成果预览保留文件自身的配色，切换主题时预览不再出现空白。
3. **新闻原始来源**：第三方转载的新闻显示原始媒体名称和网站图标，便于判断信息出处。
4. **不限量套餐用量显示**：不限量套餐的用量面板显示 Unlimited，不再显示容易被误读为上限的数值。

**性能优化：**

1. **沙箱执行速度**：提升 AI 沙箱中常用操作的执行速度。
2. **模型服务无响应时的切换**：模型服务长时间没有返回内容时，系统会在 5 分钟内重新发起请求并切换到可用的服务，此前需要等待 10 分钟，减少回答长时间无响应的情况。
3. **工具列表读取**：Agent 的工具列表改为缓存读取，工具有变更时自动更新，不再每次使用都重新读取完整列表。
4. **图表服务稳定性**：修复图表生成服务在长时间运行后内存持续增长的问题，避免因内存耗尽导致图表无法生成。

**问题修复：**

1. **委派任务的交易密码验证**：Agent 将任务委派给需要交易密码的 Agent 或工作流时，会先请你输入交易密码并暂停当前回答，验证后继续执行，不再直接报错。此项已在各端上线。
2. **行情卡片货币符号**：行情卡片按标的所属市场显示对应的货币符号，修复港股、A 股价格显示为美元符号的问题。

**使用调整：**

1. **回答生成时的页面位置**：发送问题后，页面停在你的提问处，回答在下方展开，页面不再自动滚动到底部；回答超出屏幕时，可点击「回到底部」按钮查看最新内容。目前仅在网页版上线。

## 我的 Agents 与工作流搭建

**新增功能：**

1. **新模型接入**：模型列表新增 `claude-opus-5-5`、`claude-sonnet-5-5`、`claude-haiku-5-5`、`gpt-6-sol`、`gpt-6-luna`、`gpt-6.1-sol`、`grok-4.7`、`deepseek-flash` 和百炼 `deepseek-v4.1-flash`，为 Agent 提供更多模型选项；其中 `gpt-6.1-sol` 可通过 OpenAI 直连或 OpenRouter 选用。各模型单价不同，详见模型卡。
2. **思考摘要设置**：在 Agent 配置页可设置是否将模型的长篇推理生成标题与摘要并展示给使用者；生成摘要会产生额外的模型调用。
3. **问题分类器模型选择**：在问题分类器中可选择决策模型，便于为分类任务配置所需模型。
4. **JEV 判断节点**：工作流新增基于 JEV 能力的判断节点，可在流程中使用 JEV 进行判断。

**问题修复：**

1. **工具调用重试**：工具调用遇到临时性失败时会重试，不再直接判定为失败，减少偶发问题对 Agent 运行的中断；重试可能带来少量额外消耗。
2. **工作流调用与计费配置**：新建工作流或对话流后，无需刷新即可看到调用与计费配置。
3. **结构化输出节点**：使用百炼 `deepseek-v4.1-flash` 时，结构化输出节点不再返回错误。
4. **Claude 模型调用**：修复调用 Claude 时采样参数导致请求失败的问题，减少此类参数问题对 Agent 运行的干扰。
5. **工具参数解析**：修复工具参数包含 `$defs` 引用时，参数处理导致请求失败的问题，减少这类工具的调用中断。
6. **知识库检索方式显示**：知识库检索方式不再显示多语言标识，改为正常文案，便于理解检索配置。
7. **暂停 Agent 调用结果**：修复被调用 Agent 已暂停时仍返回空的成功结果的问题，避免把这类空结果误判为成功。
8. **结果引用保留**：修复工具结果裁剪时引用证据丢失的问题，便于沿保留的引用核对信息依据。

**使用调整：**

1. **技能文件路径**：技能内读取的文件需位于该技能目录内，不再支持跨目录读取；如有依赖，请改用技能目录内的相对路径。
