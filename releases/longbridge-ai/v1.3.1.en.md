## LongbridgeAI

**New Features:**

1. **Guest Agent Trials**: Try public Agents in the gallery without signing in. Trial limits apply separately to each Agent, helping you find an assistant that fits your needs before choosing one.

**Improvements:**

1. **Background Responses and Completion Notifications**: You can step away while waiting for a LongbridgeAI answer, and the AI will continue responding in the background. Return later or after receiving a completion message to read the answer, without having to stay in the conversation.
2. **AI Landing Page Loading**: The website's `/ai` page now uses fewer resources for its initial view and loads content on demand, reducing the amount of data downloaded on your first visit so you can get to your research conversation sooner.
3. **Small-Screen Input Field**: On small screens, the input field automatically collapses into a compact pill shape to leave room for controls, making it easier to enter research questions.

**Bug Fixes:**

1. **Connector Authorization**: Fixed mismatches between the identity used to authorize a connector and the identity used at runtime, as well as repeated retries or unnecessary reauthorization prompts after authentication became invalid, reducing interruptions during research.
2. **Region Detection**: Fixed an issue that incorrectly identified users in Singapore as being in Hong Kong.

**Usage Changes:**

1. **Asset Tool Verification**: When calling tools that involve assets, you must verify your trading password before proceeding.

## My Agents and Workflow Builders

**New Features:**

1. **GPT-6 Model Support**: Model integrations now include `gpt-6-astra` through direct connections, Azure, and OpenRouter, so you can choose the route that fits your existing setup.
2. **Market Ranking Tools**: Agent Platform's built-in MCP tools now include market rankings for pre-market, regular trading, and after-hours sessions, providing data from different trading sessions for generating market updates.

**Improvements:**

1. **Intelligent Question Classification**: In customer support question classification, an LLM provides fallback classification for questions that keyword and pattern rules do not match, while maintaining backward compatibility.
2. **Direct Model Requests**: Direct model calls now automatically retry when a connection is no longer valid, reducing the impact of occasional request failures on Agent runs.

**Bug Fixes:**

1. **Environment Variable Secret Editing**: Fixed an issue where masked values shown in the editor could corrupt configured secrets when environment variables were edited and saved.
2. **Workflow Import**: Importing a workflow no longer clears the model configuration in thinking-level nodes, reducing the need to reconfigure them after import.

**Usage Changes:**

1. **Workflow Request Access**: External access from workflow HTTP request nodes and built-in request tools is now restricted to permitted destinations. If your workflow relies on external services, check that those services remain accessible.
2. **Chat HTML Rendering**: Chat messages now render only HTML tags on the allowlist; custom tags are no longer rendered. If your Agent's output relies on custom tags, check how it displays and adjust the output accordingly.
