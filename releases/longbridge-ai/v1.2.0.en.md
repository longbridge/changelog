**New:**
1. **Start chatting, no login required:** Ask the AI right away without signing up—try it first, decide later.
2. **Two new models to choose from**:  Build your Agent with Gemini 3.7 Flash or DeepSeek-V4 (GA)—pick the right model for each use case.

**Improvements:**
1. **A cleaner interface**: Refreshed global prompt styling with consistent drawer and sidebar sizing, and memory-organizing summaries now appear in a lightweight popover—less visual clutter.
2. **Clearer data sources:** All financial data references are now labeled "Longbridge Data," so you always know where the numbers come from.
3. **Tidier benefit descriptions:** Long benefit entries are truncated to one line—hover to see the full text.

**Fixes:**
1. Fixed an issue where connectors in draft status incorrectly showed an "Add" entry.
2. Fixed an issue where workflows could occasionally freeze and stop responding.
