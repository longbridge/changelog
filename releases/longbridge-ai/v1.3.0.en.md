LongbridgeAI

**New Features:**

1. **Longbridge Data Connector**: Data access has been upgraded to the official Longbridge connector, expanding coverage to include options and other data types. Access more comprehensive, high-quality data directly from Longbridge to inform your investment analysis and decisions.
2. **File Artifact Management**: In a LongbridgeAI conversation, ask AI to deliver its work as files. Files are stored independently of individual conversations for long-term access through the sidebar’s artifact management center. Use them as a record of your investment research to revisit the original reasoning and risks as you track companies over time or review past decisions, and reassess your views as new information emerges.

**Improvements:**

1. **Stock Quote Cards**: Switch time ranges and candlestick views in stock quote cards, and share market snapshots to discuss price trends and investment views with others using the same chart.
2. **Conversation Waiting Prompt**: When AI needs your input in a conversation, it displays “Waiting for your reply” and sends a notification, prompting you to add research questions or relevant information and continue the analysis.
3. **Accessibility**: Improved keyboard navigation, screen reader support and narrow-screen layouts make it easier to read analysis and ask research questions using a keyboard, screen reader or small-screen device.

## My Agents and Workflow Builders

**New Features:**

1. **Custom Context Compaction**: Configure compaction prompts in Agent nodes to specify which investment objectives, risk constraints and key assumptions to prioritize retaining in long conversations. Tailor context retention to your research tasks. Context compaction is enabled by default.
2. **Workflow Thinking Level**: In the workflow start node, use the new `sys.thinking_level` variable to reference the thinking level passed from the frontend when configuring subsequent steps.
3. **Variable Configuration**: In the configuration interface, set variables for Commands, Plugins, Hooks and OpenAPI reference channels to meet the needs of different tasks.

**Improvements:**

1. **Plugin Import**: Import plugins with the same drag-and-drop interaction used for skills to add the extensions your Agent needs.
2. **Agent Creation Flow**: The new Agent creation flow is now available to all users and replaces the previous flow.

**Bug Fixes:**

1. **Workflow Agent Run Mode**: Fixed an issue that unexpectedly reset a workflow Agent’s run mode. The mode remains fixed after creation.

**Usage Changes:**

1. **HTTP Request Scope**: Workflow HTTP request nodes can no longer access internal network addresses. If your workflow relies on internal services, review the relevant nodes and adjust how they connect.
