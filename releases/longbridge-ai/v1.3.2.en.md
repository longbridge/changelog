## LongbridgeAI

**Improvements:**

1. **Artifact Panel and Mobile Menus**: Resize the LongbridgeAI artifact panel or view it full screen to read research more comfortably. Some mobile “⋮” menus now open as bottom sheets for easier tapping.
2. **Connector Management**: LongbridgeAI connector management is now centralized in **Settings → Connectors**. The previous entries in the input field and menu have been removed. Your selected connectors are unaffected, with no reconfiguration needed.
3. **Memory System Update**: LongbridgeAI now uses a single updated memory system.

## My Agents and Workflow Building

**New Features:**

1. **New Models**: The model list now includes `qwen3.8-flash` and `gemini-3.8-flash`, giving you more options for your Agents.
2. **Plugin Downloads**: Use the download button on the plugin configuration page to export a plugin package locally, making it easier to keep and manage copies.

**Bug Fixes:**

1. **Tool Result Retrieval**: Fixed a loop in which retrieved tool results were truncated again, triggering repeated retrieval by the Agent. This reduces redundant reads within the same response.
2. **Loop Node Configuration**: Fixed false incomplete-configuration warnings caused by missing variable type definitions in workflow loop nodes, reducing misleading alerts during setup.
3. **Workflow Editing**: Fixed a page crash caused by rich-text tags when a workflow node had no title, preventing this issue from interrupting editing.
