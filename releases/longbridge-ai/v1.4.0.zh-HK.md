## LongbridgeAI

除特別註明外，以下功能更新已在 LongbridgeAI 網頁版和行動網頁版上線，Longbridge App 內建 AI 將隨 App 版本更新陸續開通；性能優化已在各端生效。

**新增功能：**

1. **AI 線上協作文件**：在對話中提出撰寫文件的需求，AI 可直接建立和編輯線上協作文件，文件自動儲存到「我的成果」，可在對話中直接查看，也可從「我的成果」開啟；在文件中留下評論，AI 會在背景處理，無需回到對話重新提問。從「我的成果」移除文件時，對應的線上文件會一併刪除且無法復原。
2. **成果支援圖片格式**：AI 產生的成果新增 PNG、JPG、GIF、WebP、SVG 五種圖片格式；圖片成果目前以下載方式取得，暫不支援在成果面板中直接預覽。產生成果時會校驗檔案類型，不支援的類型會被直接拒絕，避免產生無法開啟的檔案。
3. **回答中的行情連結**：AI 回答中寫出的股票、期權代碼（如 NVDA.US、700.HK）經校驗後顯示為行情連結，點擊即可查看行情；無法確認的代碼保持純文字，避免連結到錯誤的標的。
4. **資產與盈虧分析卡片**：在對話中詢問資產與盈虧相關問題時，分析結果以結構化卡片呈現，方便查看帳戶的資產與盈虧情況。
5. **套餐升級與風險測評入口**：在對話中，AI 可直接提供升級套餐和風險測評的操作入口；套餐列表列出各檔位功能的具體額度，方便逐項比較後選擇。
6. **思考摘要**：在啟用思考摘要的 Agent 對話中，模型的長篇推理以標題和摘要呈現，方便快速了解推理進展。

**體驗優化：**

1. **子任務耗時**：對話中的子任務列右側顯示耗時，執行中即時更新，方便了解每個子任務的進度。
2. **成果卡片與預覽**：成果卡片依檔案類型顯示不同的圖示與底色，方便區分；深色模式下成果預覽保留檔案本身的配色，切換主題時預覽不再出現空白。
3. **新聞原始來源**：第三方轉載的新聞顯示原始媒體名稱和網站圖示，方便判斷資訊出處。
4. **不限量套餐用量顯示**：不限量套餐的用量面板顯示 Unlimited，不再顯示容易被誤讀為上限的數值。

**性能優化：**

1. **沙箱執行速度**：提升 AI 沙箱中常用操作的執行速度。
2. **模型服務無回應時的切換**：模型服務長時間沒有傳回內容時，系統會在 5 分鐘內重新發出請求並切換到可用的服務，此前需要等待 10 分鐘，減少回答長時間無回應的情況。
3. **工具清單讀取**：Agent 的工具清單改為快取讀取，工具有變更時自動更新，不再每次使用都重新讀取完整清單。
4. **圖表服務穩定性**：修復圖表產生服務在長時間執行後記憶體持續增長的問題，避免因記憶體耗盡導致圖表無法產生。

**問題修復：**

1. **委派任務的交易密碼驗證**：Agent 將任務委派給需要交易密碼的 Agent 或工作流程時，會先請你輸入交易密碼並暫停目前的回答，驗證後繼續執行，不再直接報錯。此項已在各端上線。
2. **行情卡片貨幣符號**：行情卡片依標的所屬市場顯示對應的貨幣符號，修復港股、A 股價格顯示為美元符號的問題。

**使用調整：**

1. **回答生成時的頁面位置**：發送問題後，頁面停在你的提問處，回答在下方展開，頁面不再自動捲動到底部；回答超出畫面時，可點擊「回到底部」按鈕查看最新內容。目前僅在網頁版上線。

## 我的 Agents 與工作流程搭建

**新增功能：**

1. **新模型接入**：模型清單新增 `claude-opus-5-5`、`claude-sonnet-5-5`、`claude-haiku-5-5`、`gpt-6-sol`、`gpt-6-luna`、`gpt-6.1-sol`、`grok-4.7`、`deepseek-flash` 和百煉 `deepseek-v4.1-flash`，為 Agent 提供更多模型選項；其中 `gpt-6.1-sol` 可透過 OpenAI 直連或 OpenRouter 選用。各模型單價不同，詳見模型卡。
2. **思考摘要設定**：在 Agent 設定頁可設定是否將模型的長篇推理生成標題與摘要並呈現給使用者；生成摘要會產生額外的模型呼叫。
3. **問題分類器模型選擇**：在問題分類器中可選擇決策模型，方便為分類任務設定所需模型。
4. **JEV 判斷節點**：工作流程新增基於 JEV 能力的判斷節點，可在流程中使用 JEV 進行判斷。

**問題修復：**

1. **工具呼叫重試**：工具呼叫遇到暫時性失敗時會重試，不再直接判定為失敗，減少偶發問題對 Agent 執行的中斷；重試可能產生少量額外消耗。
2. **工作流程呼叫與計費設定**：新建工作流程或對話流後，無需重新整理即可看到呼叫與計費設定。
3. **結構化輸出節點**：使用百煉 `deepseek-v4.1-flash` 時，結構化輸出節點不再傳回錯誤。
4. **Claude 模型呼叫**：修復呼叫 Claude 時取樣參數導致請求失敗的問題，減少這類參數問題對 Agent 執行的干擾。
5. **工具參數解析**：修復工具參數包含 `$defs` 引用時，參數處理導致請求失敗的問題，減少這類工具的呼叫中斷。
6. **知識庫檢索方式顯示**：知識庫檢索方式不再顯示多語言識別碼，改為正常文案，方便理解檢索設定。
7. **暫停 Agent 呼叫結果**：修復被呼叫的 Agent 已暫停時仍傳回空白成功結果的問題，避免將這類空白結果誤判為成功。
8. **結果引用保留**：修復工具結果裁剪時引用證據遺失的問題，方便沿保留的引用核對資訊依據。

**使用調整：**

1. **技能檔案路徑**：技能內讀取的檔案需位於該技能目錄內，不再支援跨目錄讀取；如有依賴，請改用技能目錄內的相對路徑。
